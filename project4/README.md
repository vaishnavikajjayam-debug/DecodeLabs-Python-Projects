 General Knowledge Quiz

 📌 Project Description

The General Knowledge Quiz is a beginner-friendly Python project that asks users general knowledge questions, checks their answers, and calculates their final score.

The program uses conditional statements to determine whether an answer is correct and updates the score accordingly. It demonstrates fundamental Python programming concepts through a simple interactive quiz.

 ✨ Features

- Ask three general knowledge questions.
- Accept answers from the user.
- Check answers using `if-else` statements.
- Award one point for each correct answer.
- Display feedback for correct and incorrect answers.
- Display the final score at the end of the quiz.
- Handle uppercase and lowercase answers and surrounding spaces using string methods.

 🛠️ Technologies Used

- Python 3
- Variables
- `input()` and `print()`
- `if-else` statements
- String methods: `.strip()` and `.lower()`
- f-strings

 ▶️ How to Run

1. Install Python 3 on your computer.
2. Open a terminal in the project folder.
3. Run the following command:


python general_knowledge_quiz.py


On Windows, you can also try:


py general_knowledge_quiz.py
