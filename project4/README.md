# General Knowledge Quiz

# Description #
The General Knowledge Quiz is a beginner-friendly Python project that asks users three general knowledge questions, checks their answers, and calculates their final score. It demonstrates how conditional statements and variables can be used to create an interactive quiz application.

# Features #
- Asks three general knowledge questions.
- Checks answers using `if-else` statements.
- Awards one point for every correct answer.
- Accepts answers with different capitalizations and surrounding spaces.
- Displays feedback and the final score.

# Technologies Used #
- Python 3
- Variables
- `input()` and `print()`
- `if-else` statements
- String methods: `.strip()` and `.lower()`
- f-strings

# How to Run #
Run the following command from the project folder:


python general_knowledge_quiz.py


# Learning Outcomes #
- Understanding conditional statements and control flow.
- Managing program state using a score variable.
- Validating user input.
- Using string methods to normalize answers.
- Displaying dynamic results using f-strings.
