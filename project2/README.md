 Expense Tracker

# Description #

The Expense Tracker is a Python application designed to help users record their expenses and calculate their total spending. It demonstrates how Python can be used to perform basic calculations and organize financial information.

# Features #

- Enter expense amounts.
- Calculate the total expenses.
- Accept multiple expense entries, depending on the program's flow.
- Display the calculated total.

# Technologies Used #

- Python 3
- Variables
- User input and output
- Loops
- Arithmetic operations
- Conditional statements

# How to Run #

1. Install Python 3.
2. Open a terminal in the project folder.
3. Run the following command:


python Expense_tracker.py


# Learning Outcomes #

- Working with variables and numeric values.
- Taking input from users.
- Using loops to process multiple entries.
- Calculating totals using an accumulator.
- Applying basic programming logic to a real-world problem.
