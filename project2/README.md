 Expense Tracker

 📌 Project Description

The Expense Tracker is a Python application that helps users record their expenses and calculate their total spending. It demonstrates how programming can be used to perform basic calculations and organize financial information.

This project focuses on variables, user input, loops, arithmetic operations, and conditional statements.

 ✨ Features

- Accept expense amounts from the user.
- Calculate the total of entered expenses.
- Allow multiple expense entries, depending on the program's implementation.
- Display the total expenses.
- Provide a simple command-line interface.

 🛠️ Technologies Used

- Python 3
- Variables
- User input and output
- Loops
- Arithmetic operations
- Conditional statements

 ▶️ How to Run

1. Install Python 3 on your computer.
2. Open a terminal in the project folder.
3. Run the following command:


python Expense_tracker.py


On Windows, you can also try:


py Expense_tracker.py
