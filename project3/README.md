 Random Password Generator

 📌 Project Description

The Random Password Generator is a Python application that generates a random password based on the length entered by the user. It uses Python's randomization functionality and character collections to create a combination of letters and numbers.

This project introduces Python modules, strings, loops, and input validation.

 ✨ Features

- Allow the user to specify the password length.
- Generate a random password.
- Use letters and numbers to create password combinations.
- Validate the requested password length, if implemented.
- Display the generated password.

 🛠️ Technologies Used

- Python 3
- `random` module
- `string` module
- Variables
- Strings
- Loops
- User input and output

 ▶️ How to Run

1. Install Python 3.
2. Open a terminal in the project folder.
3. Run the following command:


python password_generator.py


On Windows, you can also try:


py password_generator.py


 💻 Example Output


===== RANDOM PASSWORD GENERATOR =====

Enter password length: 12

Generated Password: aB7kP2mQ9xRt


*Note: The generated password will vary each time the program runs.*

 🔐 Security Note

This project is intended for learning Python programming. For real-world security-sensitive passwords, use a cryptographically secure generator rather than Python's standard `random` module.
