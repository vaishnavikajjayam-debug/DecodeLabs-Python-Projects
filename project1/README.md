 To-Do List Application

# Description #

The To-Do List Application is a beginner-friendly Python project that helps users manage their daily tasks. Users can add new tasks, view their task list, and keep track of the activities they need to complete.

# Features #

- Add new tasks to the list.
- View all added tasks.
- Manage daily activities in an organized way.
- Simple and user-friendly, menu-driven interface.

# Technologies Used #

- Python 3
- Lists
- Loops
- Conditional statements
- User input and output

# How to Run #

1. Install Python 3.
2. Open a terminal in the project folder.
3. Run the following command:


python to_do_list.py


# Learning Outcomes #

- Understanding Python lists and list operations.
- Using loops and conditional statements.
- Taking user input and displaying output.
- Building a simple command-line application.
