 To-Do List Application

📌 Project Description

The To-Do List Application is a beginner-friendly Python project designed to help users manage their daily tasks. It allows users to add tasks, view their task list, and organize activities that need to be completed.

This project demonstrates the use of Python lists, loops, conditional statements, and user input to build a simple command-line application.

 ✨ Features

- Add new tasks to the task list.
- View the tasks entered by the user.
- Delete tasks, if implemented in the program.
- Display a simple menu for user interaction.
- Manage daily activities using Python.

 🛠️ Technologies Used

- Python 3
- Lists
- Loops
- Conditional statements
- User input and output

 ▶️ How to Run

1. Install Python 3 on your computer.
2. Open a terminal in the project folder.
3. Run the following command:

python to_do_list.py


If `python` is not recognized on Windows, try:


py to_do_list.py
